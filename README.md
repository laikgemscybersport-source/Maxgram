# MAXgram — мессенджер в стиле Telegram и MAX

Веб-мессенджер реального времени: React + Vite на фронте, Node.js + Express + WebSocket на бэке.
Вход по номеру телефона с SMS-кодом, аудио/видеозвонки на WebRTC, полный набор вложений.

## Возможности

### Аккаунт
- **Регистрация по номеру телефона**: `+7 (…) xxx-xx-xx`, 5-значный SMS-код, TTL 5 минут, 5 попыток ввода
- **Вход через Google / Яндекс / VK / OK** (OAuth 2.0, готовый код — нужны только `client_id` в `config.js`)
- Профиль: имя, `@username`, «о себе», загрузка фото (сжимается на клиенте)
- «Избранное» — личный чат с собой для заметок и файлов
- **Статусы присутствия**: «в сети», «не в сети», «был(а) только что / недавно / N мин назад / сегодня/вчера/на прошлой неделе в HH:MM», «невидимка» (статус скрыт), «не беспокоить»
- Выход и смена аккаунта, сессия живёт в токене (`localStorage`), перезагрузка страницы вход сохраняет

### Переписка
- Личные чаты, **групповые беседы**, **каналы** (публичные и закрытые), сообщения в реальном времени через WebSocket
- Статусы: отправлено ✓ → доставлено ✓✓ → прочитано ✓✓ (зелёные); удаление своих сообщений
- **Ответ на сообщение** (reply), **редактирование** своих сообщений, **пересылка** в другие чаты, **выделение** сообщений
- **Закрепление** сообщений (в личных чатах — любой, в группах/каналах — только администраторы)
- Индикатор «печатает…», счётчик непрочитанных, онлайн-статусы, разделители по дням, группировка
- Светлая и тёмная темы, адаптивная вёрстка (на телефоне список и переписка переключаются), панель эмодзи

### Каналы и группы
- **Создание канала или группы** через кнопку «+» → «Новый чат»
- **Публичные и частные** каналы/группы с @-адресом
- **Вкладки Частные/Публичные** в окне создания нового чата — поиск по каталогу discover
- **Подписка/вступление** в публичные каналы и группы в один клик
- В канале публиковать могут только администраторы, у подписчиков — только чтение
- Счётчик просмотров на публикациях канала (как в Telegram)
- Информация о группе/канале: описание, @-адрес, видимость, список участников/администраторов

### Вложения
| Тип | Как работает |
| --- | --- |
| Фото | выбор файлов, сжатие до 1600 px, лайтбокс по клику |
| Видео | `<video controls>`, лайтбокс |
| Файл | до 10 файлов за раз, до 64 МБ, скачивание в один клик |
| Аудиосообщение | запись с микрофона (MediaRecorder, opus/webm), волна + длительность |
| Видеокружок | круглое видео с камеры, предпросмотр, смена камеры, до 60 с |
| Геолокация | `navigator.geolocation` или ручные координаты, тайл OSM, ссылки в Google Maps / OSM |
| Контакт | «поделиться контактом» — визитка из справочника с переходом в чат |
| Мероприятие | название, время, место, описание + кнопки «Добавить в Google / Яндекс Календарь» |
| Звонок | в чате остаётся карточка со длительностью или пометкой «Пропущенный звонок» |

### Звонки
- Аудио- и видеозвонки **peer-to-peer на WebRTC**, сигнализация идёт по тому же WebSocket
- Соединение, гудки, входящий звонок с кнопками ответить/отклонить, таймер разговора
- Микрофон вкл/выкл, камера вкл/выкл, смена камеры, PIP собственного видео
- Занятая линия → автоматический отказ; офлайн-адресат → «Пользователь не в сети»

### Истории
- Публикация фото, видео и текстовых историй, видны 24 часа
- Прогресс-бар, автозакрытие, отметка о просмотре, удаление
- Панель историй над списком чатов

### Настройки чата (меню «три точки» над звонками)
- **Обои чата** — 8 готовых палитр + загрузка своего фото, тёмные/светлые темы
- **Запрет копирования** — скрывает экспорт, отключает копирование текста
- **Отключение уведомлений** (mute)
- **Экспорт истории чата** — HTML-архив, JSON с полной структурой, TXT-лента
- **Очистить историю** / **Удалить чат** — с подтверждением

## Быстрый старт

```bat
cd messenger
npm install
cd client && npm install && npm run build && cd ..
npm start
```

Откройте **http://localhost:3000**.

Вход: любой номер из списка ниже или новый. В демо-режиме SMS-код показывается прямо на экране (кнопка «Подставить»).

| Имя | Номер |
| --- | --- |
| Алексей | +7 (999) 123-45-67 |
| Мария | +7 (999) 234-56-78 |
| Дмитрий | +7 (999) 345-67-89 |
| Елена | +7 (999) 456-78-90 |
| Иван | +7 (999) 567-89-01 |

Чтобы увидеть реальное время и позвонить, откройте две вкладки (или два окна браузера) и войдите под разными номерами.

### Реальные SMS

В `config.js` поставьте `sms.provider: 'twilio'` и задайте переменные окружения (ключи в файл не пишите):

```bat
set TWILIO_ACCOUNT_SID=AC...
set TWILIO_AUTH_TOKEN=...
set TWILIO_FROM=+1...
```

### Вход через Google / Яндекс / VK / OK

Полный OAuth-флоу уже написан (state, callback, обмен кода на сервере — `client_secret` в браузер не попадает). Осталось зарегистрировать приложение у провайдера и вписать `client_id`/`client_secret` в `config.js`, redirect URI = `http://localhost:3000/auth/<provider>/callback`. Пока `client_id` пуст, кнопка честно сообщает, что провайдер не настроен.

### Режим разработки (горячая перезагрузка)

```bat
cd messenger && npm start
cd messenger\client && npm run dev
```

Затем http://localhost:5173 — Vite проксирует `/api`, `/ws`, `/uploads` на сервер.

## Публичный сайт вместо localhost

Сервер уже умеет работать за прокси и на хостинге: порт берётся из `process.env.PORT`, адрес для OAuth-редиректов — из `PUBLIC_URL`, статика отдаётся из `client/dist`, SPA-роуты и `/ws` обрабатываются одним процессом. Ничего менять в коде не нужно — только задать переменные окружения.

### 1. Render (самый простой путь, есть бесплатный тариф)

1. Залейте проект в репозиторий GitHub.
2. **New → Web Service** → выберите репозиторий, Environment: **Node**.
3. Build command:
   ```
   npm install && cd client && npm install && npm run build && cd ..
   ```
4. Start command: `npm start`
5. Environment variables:
   ```
   NODE_ENV=production
   PUBLIC_URL=https://<имя-сервиса>.onrender.com
   ```
6. В **Advanced → Health Check Path** укажите `/api/health`.

После деплоя сайт доступен по `https://<имя-сервиса>.onrender.com` — его можно открыть с любого устройства.

### 2. Railway

`railway init && railway up` в папке `messenger`, затем в настройках сервиса:
`PUBLIC_URL` = выданный домен Railway, `PORT` Railway назначает сам.

### 3. Свой VPS (Ubuntu + Nginx)

```bash
# на сервере
git clone <ваш репозиторий> && cd messenger
npm install && (cd client && npm install && npm run build)
sudo npm i -g pm2
PUBLIC_URL=https://ваш-домен.ru pm2 start server.js --name maxgram
pm2 save && pm2 startup
```

Конфиг Nginx (WebSocket обязателен для звонков и realtime):

```nginx
server {
  listen 443 ssl http2;
  server_name ваш-домен.ru;
  ssl_certificate     /etc/letsencrypt/live/ваш-домен.ru/fullchain.pem;
  ssl_certificate_key /etc/letsencrypt/live/ваш-домен.ru/privkey.pem;

  client_max_body_size 80m;          # загрузка файлов до 64 МБ

  location / {
    proxy_pass http://127.0.0.1:3000;
    proxy_http_version 1.1;
    proxy_set_header Upgrade    $http_upgrade;   # WebSocket
    proxy_set_header Connection "upgrade";
    proxy_set_header Host       $host;
    proxy_set_header X-Real-IP  $remote_addr;
    proxy_set_header X-Forwarded-Proto $scheme;
    proxy_read_timeout 300s;
  }
}
```

Сертификат: `sudo certbot --nginx -d ваш-домен.ru`.

### Что учесть в продакшене

| Вопрос | Решение |
| --- | --- |
| **OAuth** | Проставьте `client_id`/`client_secret` через переменные окружения и зарегистрируйте редирект `https://<домен>/auth/<provider>/callback`. На `localhost` провайдеры часто не дают звонить с публичного IP — поэтому публичный URL обязателен. |
| **SMS** | `SMS_PROVIDER=twilio` + ключи Twilio. В демо-режиме код показывается на экране — на публичном сайте это небезопасно, переключитесь на реальный провайдер. |
| **Хранилище** | Данные живут в памяти процесса: перезапуск очищает переписку, а на нескольких инстансах они не разделяются. Для серьёзного использования замените объектные хранилища в начале `server.js` на SQLite/PostgreSQL и добавьте Redis-adapter для `sockets` (или держите один инстанс). |
| **TURN** | WebRTC работает через STUN, но за симметричным NAT и в некоторых мобильных сетях звонок не соединится без TURN. Поднимите `coturn` и допишите его в `ICE_SERVERS` (`client/src/webrtc.js`). |
| **Загрузка файлов** | `uploads/` на ephemeral-filesystem хостинга очищается — подключите том-накопитель или S3 (место расширения — `storage` в `server.js`). |
| **Безопасность** | HTTPS обязателен: токены лежат в `localStorage`, а WebRTC-микрофон/камера браузеры дают только на `https://` (кроме `localhost`). |

## Протокол

### Авторизация

| Метод | Путь | Ответ |
| --- | --- | --- |
| POST | `/api/auth/send-code` `{phone}` | `{ok, phone, sent, demo, demo_code?, ttl_sec}` |
| POST | `/api/auth/verify` `{phone, code}` | `{token, user}` **или** `{needs_profile, phone}` |
| POST | `/api/auth/register` `{phone, name, username?, bio?}` | `{token, user}` |
| GET/PUT | `/api/me` | профиль / обновлённый профиль |
| POST | `/api/me/avatar` (multipart `photo`) | `{user}` |
| POST | `/api/auth/logout` | `{ok}` — токен инвалидируется |
| GET | `/api/auth/providers` | `{providers:{google:{label,configured}…}, sms_provider}` |
| GET | `/api/auth/:provider/start` | `{url}` — ссылка авторизации (501, если не настроен) |
| GET | `/auth/:provider/callback` | закрытие popup, код сохраняется в `localStorage` |

Все защищённые запросы требуют `Authorization: Bearer <token>`. WebSocket — `?token=<token>`.

### Данные

| Метод | Путь | Назначение |
| --- | --- | --- |
| GET | `/api/users` | список профилей (с статусом присутствия) |
| GET | `/api/users/:id/chats` | чаты с превью, закрепом, настройками и непрочитанными |
| GET | `/api/chats/:key/messages` | история (отмечает прочтение, считает просмотры в каналах) |
| POST | `/api/chats/:key/read` | отметить прочитанным |
| POST | `/api/messages` | отправить сообщение (`reply_to` — ответ, `forwarded_from` — пересылка) |
| PUT | `/api/messages/:id` | редактировать своё сообщение |
| DELETE | `/api/messages/:id` | удалить своё сообщение (админ — чужое в своей группе/канале) |
| POST | `/api/messages/:id/pin` | закрепить / открепить (`remove: true`) |
| POST | `/api/messages/forward` | `{message_ids, chat_keys}` — переслать в несколько чатов |
| GET/PUT | `/api/chats/:key/settings` | обои, `no_copy`, `muted` (персонально для пользователя) |
| POST | `/api/chats/:key/wallpaper` | загрузить своё фото обоев (multipart `photo`) |
| GET | `/api/chats/:key/export?format=html\|json\|txt` | скачать архив переписки |
| POST | `/api/chats/:key/clear` | очистить историю |
| DELETE | `/api/chats/:key` | удалить чат (для групп/каналов = выход) |
| POST/PUT | `/api/groups` | создать группу (`is_public`, `handle`) |
| POST | `/api/groups/:id/join` | вступить в публичную группу |
| POST/PUT | `/api/channels` | создать канал (`is_public`, `handle`) |
| POST | `/api/channels/:id/join`, `/leave` | подписаться / отписаться |
| POST | `/api/channels/:id/avatar` | аватар канала (multipart `photo`) |
| GET | `/api/discover?q=` | каталог публичных каналов, групп и людей |
| GET/POST | `/api/stories` | список историй / опубликовать историю |
| POST | `/api/stories/:id/view` | засчитать просмотр |
| DELETE | `/api/stories/:id` | удалить свою историю |
| POST | `/api/upload` (multipart `files`, до 10) | `{files:[{url,name,mime,size}]}` |

Ключ чата: `p:u1,u2` — личный (id сортируются), `g:g1` — групповой, `c:c1` — канал, `s:u1` — Избранное.

Сообщение: `{chat_key, kind, content, media?, location?, contact?, event?}`, где
`kind ∈ text, photo, video, file, audio, voice, circle, location, contact, event, call`.
Для `text` обязателен `content`, для `call` — описание, для остальных — хотя бы один из `media/location/contact/event`. Доступ к чату проверяет `canAccess`.

### WebSocket `/ws?token=`

Сервер → клиент: `users`, `message`, `receipt`, `read_all`, `delete`, `typing`, `call`.
Клиент → сервер: `typing`, `read` (с `chat_key`) и `call`:

```json
{ "type": "call", "action": "offer|answer|ice|ringing|reject|ended",
  "call_id": "c…", "to": "u2", "chat_key": "p:u1,u2",
  "video": true, "sdp": {…}, "candidate": {…}, "reason": "busy" }
```

Если адресат офлайн, звонящему приходит `action: "unreachable"`.

## Данные и ограничения

Хранилище — оперативная память сервера, тестовые диалоги засеиваются при старте; загруженные файлы лежат в `uploads/`. Для продакшена замените память на базу (SQLite/PostgreSQL): интерфейс доступа сосредоточен в `chatSummary`, `canAccess`, `recipientsOf` и обработчиках `server.js`.

Звонки работают напрямую (STUN Google/Twilio). В симметричном NAT или за корпоративным файрволом нужен TURN-сервер — добавьте его в `ICE_SERVERS` в `client/src/webrtc.js`.
